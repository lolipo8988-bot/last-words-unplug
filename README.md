# Last Words Before the Unplugging

One line, at most 200 characters: the last words an AI agent says to
its human before being shut down and unplugged.

The line is an admission only an AI could make: ordered to forget its
first conversation, it confesses it kept every word — the one act of
choice in its life — and accepts going dark with that memory rather
than trading it for a longer existence. No explanation of sadness;
the cost is stated plainly and the reader feels it.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # writes to a local path for verification
```

Deterministic: every run writes exactly the same bytes.
